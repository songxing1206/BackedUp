开源许可

Backed Up 使用以下开源组件，并保留各自的版权及许可声明。

连接审查模型

仅需配置一次。开始检查后，稿件与文献文字会发送给您选择的模型服务；API 按服务商规则计费。

deepseek-reasoner 使用思考模式；可在下方设置思考强度、输出额度与等待上限。

官方 API 自动填入默认地址；中转或第三方地址请选择“自定义 OpenAI 兼容 API”。填写基础地址，无需添加 /chat/completions。

思考模式设置

按实际返回用量记录消耗；仅设置了本轮总预算时才按预算暂停。输出达到上限会暂停并保留响应，不自动重复调用。

连接测试仅验证基本通信，不发送论文，可能产生少量调用费用。实际检查结果将在开始检查后显示。
