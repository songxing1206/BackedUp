# Backed Up｜引文有据

本地论文引文核查工作台：上传稿件与参考文献 PDF，检查观点与来源的支持关系，查看原文证据与 PDF 高亮。

**当前版本：0.5.4-beta。公开测试版，AI判断需要作者复核。**

## 下载与启动

- **Apple Silicon Mac（M系列）**：到 [0.5.4-beta 下载页](https://github.com/songxing1206/BackedUp/releases/tag/v0.5.4-beta) 下载 `BackedUp-0.5.4-beta-macOS-arm64.zip`，解压并打开 `BackedUp.app`，应用会启动本地后台并打开浏览器。
- 当前应用仅有临时完整性签名，未完成 Developer ID 签名及公证；macOS可能阻止打开。首次下载安装尚未在另一台干净Mac验收。
- **源码运行**：安装 Python 3.10+，macOS双击 `启动.command`，Windows运行 `启动.bat`；也可运行 `python3 bootstrap.py`（Windows用 `py -3 bootstrap.py`）。首次启动联网安装依赖。
- 服务默认打开 `http://localhost:8787/`，端口冲突时自动选择其他端口。源码启动时保持终端开启。
- Windows脚本已提供但尚未实机验收；目前不提供经过验收的Windows、Intel Mac或Linux安装包。

GitHub用于分发源码与安装包。本项目需要本地Python后台，不能直接用GitHub Pages运行完整产品。

## 使用

1. 点击“模型连接”，填写您自己的服务地址、模型ID和API Key。默认预填的SJTU地址需要相应访问资格；其他用户请改为自己可用的官方API或兼容服务。
2. 上传TXT/Markdown稿件或粘贴正文，上传本地PDF，也可批量导入PDF文件夹。
3. 点击开始检查。核查方式和预算位于高级设置；运行中逐条保存并显示结果，侧边导航同步更新。
4. 查看支持、部分支持、不支持/矛盾或无法判断，并打开PDF高亮复核。来源未匹配或证据不足不等于作者引用错误。
5. 从历史记录查看、删除记录，或导出含PDF和证据页的独立HTML报告包。

## 数据与费用

- 稿件、PDF和历史保存在用户本机，无需运营者部署云数据库。
- **语义检查会将必要稿件与文献文字发送至用户配置的模型服务商，并由用户承担API费用。** 本地运行不等于模型完全离线。
- 默认不限制本轮请求数和Token。建议先用少量材料测试；可在高级设置中设置预算。
- API Key默认仅本次服务会话使用。选择保存时采用本地权限文件，不是系统钥匙串加密存储。不要公开上传个人配置、论文或报告。
- 取消任务不保证已发出的API请求免计费；重试可能继续产生费用。

## 支持与边界

- 支持英文作者—年份引用，也可检查中文稿件中的英文文献引用；暂不支持数字引用和扫描件OCR。
- 单个PDF上限15 MB、200页、300000字符；每次最多50份。建议先上传20—30篇普通论文，长文减少数量。
- 解析、来源匹配、模型判断、摘录真实性与高亮定位分别处理。高亮准确不等于语义判断正确。
- 真实模型准确率尚未通过独立人工金标验收；存在已知复杂语义和范围判断边界，不用于替代最终学术审查。

## 开发与验证

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/verify_release.py
```

离线检查另需Node.js。当前版本已在开发Mac通过432项Python测试及前端检查，并通过安装包的PDF上传、解析、报告、高亮、历史、删除和退出冒烟。离线测试不调用真实模型，不证明语义准确率。
