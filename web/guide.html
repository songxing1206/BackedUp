BACKEDUP QUICK START

上传文件，然后开始核查

普通核查只需要稿件、来源 PDF 和检查方式。其余选项通常不必修改。

01

上传稿件

上传 `.md` 或 `.txt`，也可以直接粘贴正文。正文需要包含作者—年份引用。

02

上传来源 PDF

一次可选择多篇 PDF。系统先生成统一文档；可在来源卡片查看元数据、章节、解析质量和 Markdown 预览。

03

选择检查方式

优先使用“常规引用核查”。只有需要扩大原文范围时才使用深度全文核查。

04

开始检查

点击“开始检查”。结果、证据定位、Token 和耗时会自动保存。

结果和历史记录

检查完成后可查看结论、逐条证据、每条引用处理秒数、PDF 高亮和任务质量摘要。普通核查保存在工作台“历史记录”；A/B 或消融实验保存在“架构与实验 → 实验历史”。

默认模型

默认使用 deepseek-chat，Base URL 为 https://models.sjtu.edu.cn/api/v1。本机已保存 Key 时无需再次填写。模型调用可能产生费用，实验运行前会再次确认。

什么时候打开高级设置

普通核查默认检查全部引用。只有在需要限制 Token/请求次数、导入 BibTeX/Zotero，或修改模型连接时才需要打开高级设置。

实验怎么运行

打开“架构与实验”，点击“运行实验”，选择已有核查任务和实验目的。完成后记录会出现在实验历史中；没有人工金标时仍可查看状态、Token、请求数、耗时和执行轨迹，但不会显示虚构的准确率。

隐私与恢复

任务、历史和 API 配置保存在本机。稿件和证据文本只会按当前模型连接发送。中断后已完成结果会保留，可从历史记录继续查看。
